Description

The Online Book Store is a web-based application developed to provide users with a platform to explore books and interact with the system in an efficient and user-friendly manner. 
The application supports role-based access, allowing both customers and administrators to use the system according to their needs.

Customers can browse the platform, view information, and submit feedback, while administrators are responsible for managing the system and monitoring user 
interactions. The project demonstrates the integration of frontend design, backend development, and database management in a full-stack environment.

Objective
The objective of this project is to:
Develop a centralized platform for accessing book-related information
Implement role-based authentication for secure access
Provide a structured and interactive user interface
Demonstrate full-stack development using modern web technologies

Technologies Used
Frontend: HTML, CSS, EJS
Backend: Node.js, Express
Database: MongoDB

Customer
Customers can access the platform to browse content and interact with the website. They can also submit feedback, which is stored in the database for analysis.

Administrator
Administrators have privileged access to manage the system. They can monitor user activity and handle future functionalities such as managing books and system data.

System Features
User authentication for customers and administrators
Interactive homepage with multiple sections such as About and Contact
Feedback system for collecting user responses
Structured navigation and organized content display
Backend routing for handling different user requests

Working Principle
The system operates on a client-server architecture. When a user accesses the website, the frontend interface communicates with the backend server. 
The server processes requests and interacts with the database to retrieve or store information.
For example, when a user submits feedback, the data is sent to the server, processed, and stored in the MongoDB database. 
Similarly, login requests are validated through the backend before granting access to specific dashboards.

How to Run the Project
To run the project, the user must first set up the development environment with the required technologies such as Node.js and MongoDB. 
The project files are then obtained and dependencies are installed.
After configuring the database connection, the server is started, which hosts the application locally. The user can then access the application
through a web browser using the appropriate local address.
